# 후기 승인 운영 방법 (관리자 API)

후기는 작성 직후 `pending`(대기) 상태로 저장되고, **운영자가 `published`로 바꾼 것만** 홈페이지 '엄마들의 이야기'에 표시됩니다. 별도 관리자 화면은 없고 기존 관리자 API를 사용합니다.

## 1. 관리자 로그인 (쿠키 받기)
`ADMIN_TOKEN`은 서버 환경변수 값입니다. 명령어·메모·채팅에 그대로 적어 두지 말고, 터미널 환경변수로만 넣으세요.

```bash
# 값은 직접 입력하세요(화면·기록에 남기지 않도록 read -s 사용)
read -s ADMIN_TOKEN
curl -s -c cookie.txt -X POST "$API/api/admin/login" \
  -H "Content-Type: application/json" -H "Origin: https://www.mysaju.shop" \
  -d "{\"token\":\"$ADMIN_TOKEN\"}"
```
`$API` = 백엔드 주소. 로그인 쿠키는 `cookie.txt`에 저장됩니다(작업 후 삭제).

## 2. 대기 중인 후기 보기
```bash
curl -s -b cookie.txt -H "Origin: https://www.mysaju.shop" "$API/api/admin/reviews?status=pending"
```
각 후기의 `id`, `nickname`, `content`, `usageKind`(`paid`=구매 인증 / `trial`=무료 체험), `orderId`를 확인합니다.

## 3. 승인 / 비공개
```bash
# 공개
curl -s -b cookie.txt -X POST "$API/api/admin/reviews/<id>/status" \
  -H "Content-Type: application/json" -H "Origin: https://www.mysaju.shop" -d '{"status":"published"}'
# 비공개(사유 메모는 스팸·개인정보·욕설 같은 객관적 사유만)
curl -s -b cookie.txt -X POST "$API/api/admin/reviews/<id>/status" \
  -H "Content-Type: application/json" -H "Origin: https://www.mysaju.shop" -d '{"status":"hidden","note":"개인정보 포함"}'
```
`status`: `pending`(대기) · `published`(공개) · `hidden`(비공개). 되돌릴 수도 있습니다.

## 운영 원칙
- 실제로 작성된 후기만 공개합니다. 내용·별점을 고치거나 만들지 않습니다.
- 별점이 낮다는 이유로 숨기지 않습니다. 숨김 사유는 스팸·개인정보·욕설 등으로 한정합니다.
- 작성자가 삭제를 요청하면 `hidden` 처리 후 DB에서 삭제합니다(개인정보처리방침의 삭제 요청 안내와 같음).
